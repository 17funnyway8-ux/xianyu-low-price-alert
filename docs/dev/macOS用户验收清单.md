## 附：常见问题（FAQ）

- **双击 .app 打不开（Gatekeeper）**：本机构建本机运行无 quarantine；若从其它机器拷贝，
  右键 .app →「打开」一次；或终端执行
  `xattr -dr com.apple.quarantine "dist/闲鱼低价提醒工具.app"`。
- **Cookie 提示无法解密（dpapi1:）**：v1.7.0 起改用 Fernet 跨平台加密，旧 Windows DPAPI 密文
  无法跨平台解开 → 按「Cookie 管理 → 如何获取 Cookie」重新粘贴即可，新密文为 `fernet1:`。
- **密钥丢失**：`secret.key` 与 config.yaml 一起备份；密钥丢失后旧密文无法解密（重新粘贴 Cookie）。
- **构建体积大**：PySide6 使 .app 150~300MB，属正常；单机自用可接受。
