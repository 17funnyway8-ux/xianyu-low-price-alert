# 打包验证清单（T5 冒烟）

> 目标：验证 `dist/闲鱼低价提醒工具.exe` 在**干净临时目录**可独立运行，
> config/state 落在 **exe 同目录**，mock 跑通一轮，GUI 能启动。

## 0. 准备

```bat
:: 构建
python -m pip install -r requirements-build.txt
python -m PyInstaller "build/闲鱼低价提醒工具.spec" --noconfirm

:: 干净目录
mkdir %TEMP%\xy_smoke
copy dist\闲鱼低价提醒工具.exe %TEMP%\xy_smoke\
cd /d %TEMP%\xy_smoke
```

## 2. GUI 冒烟

```bat
start "" "闲鱼低价提醒工具.exe"        :: 后台拉起
timeout /t 5
tasklist | findstr 闲鱼               :: 期望进程存在（不闪退）
taskkill /IM 闲鱼低价提醒工具.exe /F   :: 关闭
```

期望：GUI 窗口正常显示（不白屏、不闪退），退出后 exe 同目录出现 config.yaml。

## 3. Cookie 说明（标准版）

- 标准版不含 playwright → GUI「获取 Cookie」方式一不可用，需用**方式二手动粘贴**；
- 或命令行 `login --cookie-string "..."`（frozen 打包版会自动把明文迁移为 DPAPI 密文）；
- `monitor.cookies` 以 `dpapi1:` 前缀密文落盘；换机/换用户需重新登录。

## 4. 体积红线

- 标准版 exe 期望 **15~25MB**；
- 若 >50MB → playwright 未排干净，检查 spec 的 `excludes`（`playwright` 整包）。
